## Validation

Run frontend tests under Node 25 with its experimental web storage disabled.

```sh
NODE_OPTIONS=--no-experimental-webstorage npm test
npm run build
npm run host:build
NODE_OPTIONS=--no-experimental-webstorage npm run test:host
cargo fmt --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test
```

Native probes used Claude Code 2.1.287, disposable profiles, a dummy key, and a fake localhost API. The tool-policy probe asked the CLI to Write despite an existing allow policy. Its request advertised no tools and it created no file. A read-only probe advertised only Read, Glob, and Grep, read a fixture, and returned the answer on its second model request. The initialization acknowledgement matched the helper's request ID.

The packaged GUI, Windows, Linux, live OAuth quota endpoint, and an installed CLI update were not exercised. UI tests used happy-dom. Quota tests cover legacy fields and the scoped payload shape reported in issue 674. Form elicitation supports primitive string, enum, boolean, and numeric fields. Unsupported schemas display a status message and decline.
