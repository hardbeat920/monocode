Implementation notes

  • Row: SubagentPanel in AgentTranscript.tsx, unchanged in shape: -mx-1.5 px-1.5 py-1 rounded-md gap-2, hover and open bg-content/8, name text-sm text-content/75, meta text-[12px] text-content/40 max-w-[55%], ChevronRight size-3.5 text-content/35. Leading glyph is HarnessIcon instead of ProjectMascot, because the harness is part of "which agent".
  • Live: Shimmer on the name, as SubagentPanel does with active. Elapsed time comes from the child session's run state.
  • Opened body: .zen-phase-step rail; reply uses UpdateReply's line-clamp-4 plus "Show more". Raw childId, full model id and "Request N" live only in a text-[11px] text-content/35 mono line here.
  • Status words: the STATUS map in SessionUpdateCard.tsx, reworded lower-case for the meta slot: settled "replied" (Check, emerald-400), stopped "stopped by you" (Square, content/50), failed (CircleX, red-400), approval "needs your approval" (CircleAlert, amber-400), question "has a question" (CircleHelp, amber-400). interrupted and removed would follow the same slot.
  • Second line: only for failed (error, red-400) and blocked (label plus a link to the child), text-[12.5px], indented to the name.
  • Replaces: AssignmentCard becomes the task-sent row; the "Session updates" label and SessionUpdateCard become update rows rendered at the head of the resumed turn, outside any user bubble.
  • Child tab: UserMessageBlock bubble when the block has acceptedAssignment; sender line styled like the existing "Session update" label (text-xs font-medium text-content/55); tint --color-mention at 10% with a 16% inset ring. "Sent to main" is one more item after the clock in the turn footer.
  • Trade-off: the quietest option and the closest to existing code, but a settled reply is invisible until opened, so the operator's own prose has to say what came back.
